
## Connect to robot
On this page you can see all the available robots to connect to in a list. Select the robot you wish to use and press "connect to robot". 


## Blockly
### Making your program
To create a program using Blockly, follow these steps:
1. Drag and drop the desired blocks from the left sidebar onto the workspace in the middle.
2. Arrange the blocks in the desired order to define the sequence of actions.
3. Connect the blocks together to create logical connections between them.

### Executing your program
Once you have created your program, you can execute it by following these steps:
1. Click on the green run button located in the toolbar.
2. The code generated by your blocks will be displayed below the button.
3. This code will be uploaded to the robot and executed accordingly.

Enjoy using Blockly to program your robot!
