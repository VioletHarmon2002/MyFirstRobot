# End user documentation

### Purpose

This interface allows you to controll a robot's movements, animations and emotes using simple buttons.


#### Features

1. **Animations**
    - `Stand`: Makes the robot stand upright.
    - `Sit`: Puts the robot in a seated position.
    - `Lay Down`: Makes the robot lie down.
    - `Wave`: The robot waves its paw.

2. **Emotes**
    - `Smile`: The robot displays a smiling expression.
    - `Frown`: The robot shows a frowning expression.
    - `Cry`: The robot simulates crying.
    - `Sleep`: The robot enters a sleeping pose.

3. **Movement**
    - `Direction controls`: Buttons to move the robot forward, backward, left or right


#### Troubleshooting

1. **No response from robot**
    - Ensure the robot is powered on and connected to the network

2. **Error messages**
    - `Failed to create socket`: The control page has an issue, try restarting it.
    - `Failed to connect to server`: The robot is either offline or there is something wrong with the server
