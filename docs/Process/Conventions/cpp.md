In the team we are going to use certain coding conventions for the C++ code.

- File Naming: Use CamelCase for filenames (e.g., Face.cpp, Face.h).
- Variable Naming: Use lowerCamelCase for variable names (e.g., isConnected).
- Function Naming: Use lowerCamelCase for function names (e.g., moveForward()).
- Class Naming: Use CamelCase for class names (e.g., RobotDog).
- Maintain a consistent style across the project to improve readability and make debugging easier.
- File Organization: Use a separate .cpp file for class implementation and a corresponding .h file for declarations.
