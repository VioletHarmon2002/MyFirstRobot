# The head

## What to use for the head

We have a couple of idea's to use for the head. We could use a Matrix display, or an 0.96" oled screen. 

## Matrix display

The matrix display is cheaper, but it a lot bigger. 

A couple of options i found which we could use are:

|item | cost | link |
|---|---|---|
|Loose matrix | 0.80 | [matrix](https://www.tinytronics.nl/nl/verlichting/matrix/8x8-led-matrix-3mm-pitch-rood)|
| matrix I2C | 4.00 | [matrix I2C](https://www.tinytronics.nl/nl/verlichting/matrix/8x8-led-matrix-i2c-communicatie-rood)|
| Matrix MAX7219 Module | 4.00 | [matrix MAX7219](https://www.tinytronics.nl/nl/verlichting/matrix/led-matrix-8*8-met-max7219-module) |

The loose matrix is very cheap but then we would have to put a lot more effort into it then if we buy the other options. 

The matrix I2C is very easy to assamble, but doesn't have holes so we could mount it vertical. 

the matrix MAX7219 has the ease of use but also holes so we could mount it vertically. 

So from the matrix displays the MAX7219 module would be best.


## OLED

For the OLED we have pretty much one option. An [0.96 inch OLED](https://www.tinytronics.nl/nl/displays/oled/0.96-inch-oled-display-128*64-pixels-blauw-i2c) screen. 

This screen is very small and light. So it would fit our design for the robot. It also has the ease of use and the holes for assembly as the matrix, but it is more expensive. This OLED is **7.00 euro's**.  


## Conclusion

So we have 2 options, we have the matrix display and the OLED screen.

item | cost | link |
|---|---|---|
| Matrix MAX7219 Module | 4.00 | [matrix MAX7219](https://www.tinytronics.nl/nl/verlichting/matrix/led-matrix-8*8-met-max7219-module) |
| 0.96" OLED | 7.00 | [0.96 inch OLED](https://www.tinytronics.nl/nl/displays/oled/0.96-inch-oled-display-128*64-pixels-blauw-i2c) screen |

The matrix is cheaper but a lot bigger and to make facial expressions on it would be more difficult then the OLED. Because with the oled we could show images and or emoji's. 

by following [this](https://www.instructables.com/How-to-Display-Images-on-OLED-Using-Arduino/) tutorial, we can easilly show images on the oled, which would make the robot more alive and it will be very easy if the user want to have other images shown on the screen.

So my prefrence would go out to the OLED screen, even if it is more expencive, because it has all the pro's of the matrix display's and it is more easy to work with and to expand.
