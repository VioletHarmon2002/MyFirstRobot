# Scrum poker

At the start of sprint 2 we wanted to have a good sprint board so we can start working. To do this, we had to create good user stories. We also did all of this together with the whole team.

We started with a list of all epics which we gathered from the requirements list. Per epic, we wrote down what had to be done to finish the epic. The list was divided into sub-epics and per sub-epic we wrote down what had to be done to finish the sub-epic. This way we created a list of user stories. Then, we created a list of action point or tasks per user stories. This way we had a good overview of what had to be done. All the epics, sub-epics and user stories were added to our gitlab board.
