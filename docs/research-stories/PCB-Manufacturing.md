## Design PCBs

### [KiCad](https://www.kicad.org/)

### Steps (a symbol is a part, but in the schematic):
1. Create schematic symbols (lots of common parts already have symbols)
2. Make schematic
3. Create part footprints (again, big library of parts already exists)
4. Associate footprints to symbols
5. Place parts and define outline
6. Create board layout
