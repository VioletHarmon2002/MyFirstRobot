# End User Documentation

## Description

This document provides instructions for connecting to and controlling a robot using a QR code generated by the ESP32. The QR code contains the id of the ESP32, which is used to establish a connection.


## Connecting to the robot

1. Scan the QR Code:

- Use a QR code scanner on your smartphone or a dedicated QR code scanning device.
- Scan the printed QR code to connect to the robot

2. Control the Robot:

- Once connected, you can use the robot control application to send commands to the robot.
- Use the provided controls to control the robot.
