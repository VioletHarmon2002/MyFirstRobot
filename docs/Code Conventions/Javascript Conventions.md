# JavaScript Conventions

1. **Variable and Function Naming**
    - Use `camelCase` for variable and function names.
    - Use `PascalCase` for class and constructor functions.

2. **Braces and Blocks**
    - Always use braces `{}` for all blocks, even for single-line conditionals or loops.

3. **Indentation**
    - Use 2 spaces for consistent indentation.

4. **Avoid Global Variables**
    - Encapsulate variables within functions or modules.

5. **Use `const` and `let`**
    - Prefer `const` for variables that do not change.
    - Use `let` for variables that might be reassigned.
    - Avoid `var`.

6. **Semicolon**
    - Always end in `semicolon` to avoid errors
